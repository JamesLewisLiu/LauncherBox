# LauncherBox

A portable Windows 10/11 x64 arcade launcher for your BAT files.

Download `LauncherBox-Portable-Windows-x64` from [Actions](https://github.com/JamesLewisLiu/LauncherBox/actions/workflows/build.yml), extract it, and run `LauncherBox.exe`. Open the gear menu to add games and bind controls.

**F11 / Alt+Enter** toggles fullscreen. **Esc / Alt+F4** exits. See the [usage guide](docs/usage.md) for controls, startup, and local builds.
