# LauncherBox

A Windows 10/11 x64 arcade launcher for your BAT files.

Download `LauncherBox-Windows-x64` from a successful [Actions build](https://github.com/JamesLewisLiu/LauncherBox/actions/workflows/build.yml), extract it, and run `LauncherBox.exe`. Press **F2** to add games, **← / →** to browse, **Enter** to play, and **F11** for fullscreen.

Run `Build.cmd` on Windows to compile locally. See the [usage guide](docs/usage.md) for sign-in startup and BAT behavior.
